# retail-sales-analytics-dashboard
Retail Sales Analytics Dashboard
Project Overview
This project focuses on analyzing retail sales data to support business decision-making using data analytics, visualization, and customer segmentation techniques.
An interactive analytics prototype was developed using Python and Streamlit, while a professional business intelligence dashboard was created using Power BI.
The system transforms raw retail transaction data into actionable insights related to sales trends, customer behavior, profitability, and business performance.

Objectives
	•	Analyze retail sales performance
	•	Identify customer behavior patterns
	•	Perform RFM customer segmentation
	•	Visualize business KPIs
	•	Generate data-driven business recommendations
	•	Improve decision-making through interactive dashboards

Dataset
	•	Superstore Sales Dataset (Kaggle)
	•	9,994 retail transaction records
	•	Data spanning 2014–2017
	•	793 unique customers
	•	Multiple product categories and regions

Technologies Used
	•	Python
	•	Pandas
	•	Streamlit
	•	Plotly
	•	Power BI
	•	Statsmodels
	•	VS Code

Key Features
Exploratory Data Analysis (EDA)
	•	Sales and profit analysis
	•	Regional performance comparison
	•	Product category insights
	•	Trend analysis
Customer Segmentation
Implemented RFM (Recency, Frequency, Monetary) analysis to classify customers into:
	•	Champions
	•	Loyal Customers
	•	Potential Loyalists
	•	At-Risk Customers
	•	Lost Customers
Interactive Dashboards
Built visual dashboards including:
	•	KPI cards
	•	Line charts
	•	Bar charts
	•	Pie charts
	•	Scatter plots
	•	Interactive filters
Business Intelligence Insights
Generated insights related to:
	•	Revenue growth
	•	Profit margins
	•	Customer behavior
	•	Discount impact
	•	Seasonal sales trends

Major Findings
	•	Consumer segment generated the highest revenue
	•	Home Office segment achieved the highest profit margin
	•	Excessive discounting negatively impacted profits
	•	Seasonal sales peaks occurred during Q4
	•	RFM analysis identified high-value and at-risk customers
